# PHP & MySQL Web Applications

A collection of database-driven web applications built with PHP and MySQL. These projects demonstrate relational database design, SQL queries, server-side development, AJAX, MVC architecture, and dynamic data management.

## Projects

### MVC Student Manager

A database-driven student management application organized using an MVC-style architecture.

#### Features
- Displays student records stored in a MySQL database
- Filters students by academic major
- Adds and deletes student records
- Uses relational student and major tables
- Separates application logic into model, view, and controller components
- Includes shared page components and database error handling

### AJAX Student Search

An interactive student search application that retrieves information from a MySQL database using PHP and AJAX.

#### Features
- Searches student records using user-provided criteria
- Retrieves database results dynamically
- Supports GPA-based student searches
- Searches for individual student records
- Updates results without requiring a full page reload
- Includes database connection and error handling
